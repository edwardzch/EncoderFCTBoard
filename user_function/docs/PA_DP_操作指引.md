# PA / DP 参数操作指引

> **适用固件**: EncoderFCTBoard V1.0  
> **更新日期**: 2026-02-27

---

## 1. 按键说明

| 按键 | 名称 | 功能 |
|------|------|------|
| KEY1 | 功能 (Mode) | 切换 PA / dP 参数组；编辑模式下放弃修改并退出 |
| KEY2 | 加 (Up) | 数值递增；长按连发加速 |
| KEY3 | 减 (Down) | 数值递减；长按连发加速 |
| KEY4 | 移位 (Shift) | 短按：移动光标 / 翻页；长按：进入编辑 / 保存 |
| KEY2+KEY3 | 组合 | 错误模式下复位报警 |

---

## 2. 操作流程

### 2.1 开机

数码管依次显示 `Etest`（打字机动画），按 **KEY1** 进入参数选择界面。

> 若 Flash 为空（首次使用），开机后显示 `Err.10`，按 KEY2+KEY3 复位后可正常操作。

### 2.2 选择参数

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | KEY1 | 在 PA（可读写）和 dP（只读）组之间切换 |
| 2 | KEY2 / KEY3 | 调整参数编号（如 PA000 → PA001） |
| 3 | KEY4 短按 | 移动光标到十位 / 百位，配合 KEY2/KEY3 快速跳转 |
| 4 | KEY4 长按 | 进入编辑 / 查看模式 |

### 2.3 编辑参数（仅 PA 组）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | KEY4 长按 | 从选择界面进入编辑 |
| 2 | KEY2 / KEY3 | 调整当前光标位的数值 |
| 3 | KEY4 短按 | 移动光标（DEC/HEX: 个→十→百→千；BIN: bit0→bit1→bit2→bit3） |
| 4 | KEY4 长按 | **保存**并退出编辑（数码管闪烁提示） |
| 5 | KEY1 | **放弃**修改，直接退出编辑（不保存） |

### 2.4 查看 DP 参数（只读）

DP 组进入编辑模式后无法修改数值，仅可查看。  
特殊参数（如 DP001 继电器状态）支持 KEY2/KEY3 翻页。

---

## 3. PA 参数一览表

| 参数 | 功能 | 显示格式 | 范围 | 默认值 | 保存后动作 |
|------|------|----------|------|--------|-----------|
| PA000 | Modbus 从机地址 | 十进制 | 1 ~ 255 | 5 | 重配 Modbus |
| PA001 | 波特率 / 100 | 十进制 | 12 ~ 1152 | 576 (=57600) | 重配 Modbus |
| PA002 | 校验位 | 文字 | 0=nonE, 1=odd, 2=EuEn | 1 (odd) | 重配 Modbus |
| PA003 | 继电器 K1-K4 | 二进制 | b.0000 ~ b.1111 | 0 | 设置继电器 |
| PA004 | 继电器 K5-K8 | 二进制 | b.0000 ~ b.1111 | 0 | 设置继电器 |
| PA005 | 恢复出厂设置 | 十进制 | 0 ~ 9999 | 0 | 输入 1234 触发恢复 |
| PA006 ~ PA009 | 预留 | — | — | 0 | — |
| PA010 | ReadReg 地址 | 十六进制 (H.) | 0x0000 ~ 0xFFFF | 0 | — |
| PA011 | WriteReg 地址 | 十六进制 (H.) | 0x0000 ~ 0xFFFF | 0 | — |
| PA012 | WriteReg 数据 | 十六进制 (H.) | 0x0000 ~ 0xFFFF | 0 | 立即写入编码器寄存器 |

---

## 4. DP 参数一览表

| 参数 | 功能 | 显示格式 | 说明 |
|------|------|----------|------|
| DP000 | 固件版本 | 十进制 | V1.0 显示为 10 |
| DP001 | 继电器状态 | 二进制 | K1-K4 / K5-K8 分页，KEY2/KEY3 切换 |
| DP002 ~ DP009 | 预留 | — | — |
| DP010 | ReadReg 返回值 | 十六进制 (H.) | 进入时自动读取 PA010 地址的编码器寄存器 |

---

## 5. 特殊操作说明

### 5.1 恢复出厂设置 (PA005)

1. 选择 **PA005**，长按 KEY4 进入编辑
2. 将数值调整为 **1234**
3. 长按 KEY4 保存
4. 系统自动执行：
   - 清除所有 PA 参数
   - 写入默认值（PA000=5, PA001=576, PA002=1）
   - 保存到 Flash
   - 重配 Modbus 通讯
   - 断开所有继电器
5. PA005 自动复位为 0（防止重复触发）

> **注意**：恢复操作不可撤销，所有自定义参数将被重置。

### 5.2 编码器寄存器读取

1. 在 **PA010** 中设置要读取的编码器寄存器地址（HEX）
2. 切换到 **DP010**，长按 KEY4 进入查看
3. 系统自动读取 PA010 中指定地址的寄存器值并显示

### 5.3 编码器寄存器写入

1. 在 **PA011** 中设置要写入的编码器寄存器地址（HEX）
2. 在 **PA012** 中设置要写入的数据值（HEX）
3. 长按 KEY4 保存 PA012 后，系统**立即执行写入**

> **注意**：写入操作直接作用于编码器硬件，请确认地址和数值正确。

### 5.4 继电器面板控制

- **PA003**：控制 K1~K4（4位二进制，bit0=K1, bit3=K4）
- **PA004**：控制 K5~K8（4位二进制，bit0=K5, bit3=K8）
- 保存后立即生效
- 通过 **DP001** 实时查看 K1~K8 状态（KEY2 查看 K5-K8, KEY3 查看 K1-K4）

## 7. 错误码一览表

| 错误码 | 数码管显示 | 说明 | 处理方式 |
|--------|-----------|------|----------|
| Err.01 | `Err.01` | 通讯超时 | 检查编码器连接 |
| Err.02 | `Err.02` | 编码器 CRC 校验错误 | 检查通讯线路 |
| Err.03 | `Err.03` | 地址错误 | 检查寄存器地址 |
| Err.04 | `Err.04` | Modbus CRC 错误 | 检查 Modbus 帧 |
| Err.05 | `Err.05` | 未设置编码器类型 | 通过 Modbus 设置编码器类型 |
| Err.06 | `Err.06` | SN 位数错误 | 检查 SN 命令格式 |
| Err.07 | `Err.07` | 通讯长度错误 | 检查 Modbus 帧长度 |
| Err.08 | `Err.08` | 功能码不支持 | 检查 Modbus 功能码 |
| Err.09 | `Err.09` | 从机地址不匹配 | 检查 Modbus 从机地址 |
| Err.10 | `Err.10` | Flash 为空（首次使用） | 按 KEY2+KEY3 复位，使用默认值 |
| Err.11 | `Err.11` | Flash CRC 校验失败 | 数据损坏，按 KEY2+KEY3 复位后恢复出厂设置 |

> **复位方法**：同时按住 KEY2 + KEY3 约 50ms 即可清除错误。

## 8. Modbus 远程访问

PA/DP 参数也可通过 Modbus RTU 远程读写：

- **通讯参数**：由 PA000(地址)、PA001(波特率)、PA002(校验位) 决定
- **继电器控制**：Modbus 地址 `0x1000` 按位掩码控制 K1-K8
- **编码器操作**：Modbus 地址 `0x0000-0x07FF` 范围
- **功能码**：支持 03H(读)、06H(写单个)、10H(写多个)

## 9. 开发者指南：新增 PA / DP 参数

> 以下说明新增一个 PA 或 DP 参数时，需要修改的文件和位置。

### 9.1 涉及文件总览

| 步骤 | 文件 | 修改内容 |
|------|------|----------|
| ① | `Parameter_Module.h` | 确认 `PA_SIZE` / `DP_SIZE` 是否够用 |
| ② | `Parameter_Module.c` → `PM_Init()` | 设置出厂默认值 |
| ③ | `Parameter_Module.c` → `PM_GetConfig()` | 定义参数属性（格式/范围/位宽） |
| ④ | `DigitalTube_Control.c` → `DTC_Key_Logic()` | 保存后动作（PA 组） |
| ⑤ | `DigitalTube_Control.c` → `DTC_Key_Logic()` | 进入编辑时的特殊处理（DP 组只读参数） |
| ⑥ | `DigitalTube_Control.c` → `DTC_Update_Buffer()` | 特殊显示处理（可选） |

---

### 9.2 步骤详解

#### ① 检查缓冲区大小 (`Parameter_Module.h`)

当前 PA 和 DP 各有 60 个槽位：

```c
#define PA_SIZE 60  // PA 参数组容量
#define DP_SIZE 60  // dP 参数组容量
```

> 只要新参数编号 < 60（如 PA020），无需修改。若超出需增大此值。  
> ⚠️ 修改 `PA_SIZE` 会影响 Flash 记录大小，需同步确认 Flash 布局。

---

#### ② 设置出厂默认值 (`Parameter_Module.c` → `PM_Init()`)

在 `// PA 参数出厂默认值` 区域添加一行：

```c
// 示例：新增 PA020 编码器分辨率，默认 17
PA_Buffer[20] = 17;   // PA020: 编码器分辨率 (位), 默认 17
```

> DP 参数只需在 `// DP 参数初始值` 区域添加：

```c
DP_Buffer[2] = 0;     // DP002: 某运行状态 (实时更新)
```

---

#### ③ 定义参数属性 (`Parameter_Module.c` → `PM_GetConfig()`)

在对应的 `switch` 中添加 `case`：

**PA 组示例**（可读写）:

```c
// ================= PA 组 =================
if (group == 0) {
    switch (index) {
        // ... 已有的 case ...

        case 20: // PA020: 编码器分辨率 (DEC, 1-23)
            cfg.Min = 1;
            cfg.Max = 23;
            break;

        // HEX 格式示例:
        case 21: // PA021: 某寄存器地址 (HEX)
            cfg.Format = FMT_HEX;
            cfg.Min = 0;
            cfg.Max = 0xFFFF;
            break;

        // BIN 格式示例:
        case 22: // PA022: 某二进制开关 (BIN)
            cfg.Format = FMT_BIN;
            cfg.Min = 0;
            cfg.Max = 0xF;
            break;
    }
}
```

**DP 组示例**（只读）:

```c
// ================= DP 组 (只读) =================
if (group == 1) {
    switch (index) {
        // ... 已有的 case ...

        case 2: // DP002: 某状态值 (DEC)
            cfg.Min = 0;
            cfg.Max = 9999;
            break;
    }
}
```

> **属性说明**:
> - `Format`: `FMT_DEC`(默认) / `FMT_HEX` / `FMT_BIN`
> - `Width`: `BIT_16`(默认,不分页) / `BIT_32`(启用分页)
> - `Sign`: `UNSIGNED`(默认) / `SIGNED`
> - `Min` / `Max`: 编辑时的限幅范围
> - 若使用默认属性（16位无符号十进制, 0~9999），可以不添加 case

---

#### ④ 保存后动作 (`DigitalTube_Control.c` → `DTC_Key_Logic()`)

PA 参数保存后想触发某个操作，在长按保存的 `switch (DTC_Dev.ParamNum)` 中添加：

```c
// 在 DTC_Key_Logic 的保存逻辑区域
if (DTC_Dev.GroupIdx == 0) {
    switch (DTC_Dev.ParamNum) {
        // ... 已有的 case ...

        case 20: // PA020: 编码器分辨率 → 保存后重新初始化
            // 调用你的业务函数
            EncoderSetResolution(PA_Buffer[20]);
            break;
    }
}
```

> 若保存后无需特殊动作，不添加 case 即可（仅写入 Flash）。

---

#### ⑤ DP 进入编辑时的刷新 (`DigitalTube_Control.c` → `DTC_Key_Logic()`)

DP 参数为只读，进入查看时通常需要实时刷新数据：

```c
// 在 DTC_Key_Logic 的进入编辑逻辑区域
if (DTC_Dev.GroupIdx == 1) {
    // ... 已有的 if ...

    else if (DTC_Dev.ParamNum == 2) {
        // DP002: 从某硬件读取当前状态
        DP_Buffer[2] = (int32_t)SomeHardware_GetStatus();
    }
}
```

---

#### ⑥ 特殊显示处理 (`DigitalTube_Control.c` → `DTC_Update_Buffer()`) [可选]

若需要如 PA002（nonE/odd/EuEn）那样的自定义文字显示，在 `DTC_Update_Buffer()` 中添加特殊处理：

```c
// 特殊文字显示: PA020
if (DTC_Dev.GroupIdx == 0 && DTC_Dev.ParamNum == 20) {
    // 自定义段码填充
    // ...
    return;
}
```

> 大多数参数使用默认的 DEC/HEX/BIN 格式即可，无需此步骤。
